# meta-ads — סקיל לניהול פרסום במטא דרך Claude Code

> נבנה ע"י **Roey Treister** עבור הוורקשופ "Claude Code × פרסום במטא".
> כל הזכויות שמורות — ראה [LICENSE](../LICENSE).

ברוכים הבאים. זה הסקיל הראשון משני הסקילים שקיבלת בוורקשופ. הוא מאפשר ל-Claude Code לקרוא, לנתח, ולנהל קמפיינים במטא ישירות מולך — ב-API.

---

## מה הסקיל הזה יודע לעשות?

**קריאה (לא מסוכן):**
- שליפת ביצועים של קמפיינים (CTR, CPM, ROAS, CPA, וכו')
- ניתוח Creative Fatigue (תדירות וירידת CTR)
- חיתוכים לפי גיל, מין, פלטפורמה, מיקום, מכשיר
- זיהוי אנומליות (השוואה תקופה לתקופה)
- ניתוח Funnel — איפה אנשים נופלים בדרך
- ניתוח קמפיינים של Click-to-WhatsApp

**כתיבה (מסוכן — דורש אישור מפורש לכל פעולה):**
- הקפאה / הפעלה של מודעה, סט, או קמפיין שלם
- שינוי תקציב (יומי או lifetime)
- שכפול מודעה / סט / קמפיין שלם
- **יצירת קמפיין מאפס** עם הכל — קמפיין, סטים, קריאייטיבים, מודעות

## התקנה

### שלב 1 — להעתיק לתיקיית הסקילים של Claude

ההורדה שקיבלת היא תיקייה בשם `meta-ads`. תעתיק אותה כולה ל:

**Windows:**
```
C:\Users\<your-user>\.claude\skills\meta-ads\
```

**macOS / Linux:**
```
~/.claude/skills/meta-ads/
```

אחרי שהתיקייה במקום, Claude Code יראה אותה אוטומטית בפעם הבאה שתפעיל אותו.

### שלב 2 — להתקין את Python ואת ספריית `requests`

**Windows:**
```powershell
python --version
python -m pip install --user requests
```

**macOS / Linux:**
```bash
python3 --version
python3 -m pip install --user requests
```

אם `python` לא מוכר — תוריד את Python מ-https://python.org ותסמן בהתקנה "Add to PATH".

### שלב 3 — להוציא טוקן ממטא + לקבוע את חשבון המודעות

תעבור על המסמך `references/setup.md`. הוא מנחה אותך צעד-צעד דרך:
- יצירת אפליקציה ב-developers.facebook.com
- בחירה בין שתי דרכים להוציא טוקן (Path A או Path B)
- מציאת ה-Ad Account ID שלך
- מילוי קובץ `.env`

הצעד הזה לוקח 15-25 דקות בפעם הראשונה. **אחרי זה לא תצטרך לעשות אותו שוב.**

### שלב 4 — לוודא שהכל עובד

```powershell
# Windows
cd C:\Users\<your-user>\.claude\skills\meta-ads
python scripts/auth_check.py
```

אם רואים `"ok": true` — סיימנו. אפשר להתחיל לעבוד.

## איך משתמשים בפועל?

פשוט פותחים שיחה עם Claude Code בתיקייה כלשהי, ושואלים בעברית:

```
איך הקמפיינים שלי עבדו ב-30 הימים האחרונים?
```

```
תיצור לי קמפיין חדש לקוורס שלי, יעד Conversions, תקציב 100 שקל ליום, קהל יעד בעלי עסקים בישראל 30-55. הקריאייטיב נמצא בתיקייה C:\creatives\new\.
תייצר את זה PAUSED.
```

```
תפעיל בדיקת fatigue על הקמפיין הראשי שלי
```

Claude יחליט אילו סקריפטים להפעיל, ירוץ עליהם, ויחזיר לך את התשובה בשפה שאתה כתבת.

## עבודה עם כמה חשבונות (אופציונלי)

אם אתה מנהל יותר מחשבון אחד (למשל החשבון העסקי שלך + 2 לקוחות), אפשר לקבוע את כולם פעם אחת בקובץ `accounts.json`.

תעתיק את `accounts.example.json` ל-`accounts.json`, תפתח אותו, ותמלא את הטוקנים והחשבונות שלך. אחרי זה תוכל להגיד ל-Claude:

```
תוציא לי דוח 7 ימים על לקוח א
```

ו-Claude ימצא את החשבון של "לקוח א" אוטומטית לפי ה-aliases שהגדרת.

**אם יש לך רק חשבון אחד** — תדלג על השלב הזה. ה-`.env` מספיק.

## ⚠️ כללי בטיחות

הסקיל מבצע פעולות אמיתיות מול חשבון המודעות שלך. הכלל הבסיסי: **כל פעולת כתיבה (הקפאה, שינוי תקציב, יצירה) דורשת אישור מפורש שלך בצ'אט לפני שהיא קורית.**

קרא את `references/write-actions.md` לפני שאתה מתחיל לעשות פעולות כתיבה. שם מפורטים גם תרחישי הסכנה הנפוצים והגדרות הבטיחות המובנות (cap של 2x על שינוי תקציב, dry-run לפני create, וכו').

**טוקנים הם כמו סיסמאות לחשבון המודעות שלך.** אל תשתף אותם, אל תשמור אותם ב-git ציבורי, ואל תשלח אותם בצ'אט/אימייל. אם הטוקן דלף — תייצר חדש מיד.

## אם משהו לא עובד

קרא את `references/troubleshooting.md`. שם מכוסים כל המקרים הנפוצים: טוקן פג, קוד 200, שגיאות הרשאות, בעיות UTF-8 בעברית ב-Windows, וכו'.

אם עדיין תקוע — תעתיק את הפלט המלא של הסקריפט שנכשל, ותדביק ל-Claude. הוא יבין מה הבעיה.
